# 🍕 Pizzeria Bella Manu 🍕

#### Link del Sito: https://m4nu14.github.io/PizzeriaBellaManu/

## Il progetto

Il sito è realizzato con **HTML e CSS**, senza framework o dipendenze da installare. La pagina principale presenta la pizzeria; la pagina contatti raccoglie indirizzo, telefono e orari. La pagina delle bibite presenta una selezione di bevande, mentre le pagine di pizze e dolci sono predisposte per i rispettivi menu.

## Pagine

- **Home** — Presentazione della pizzeria.
- **Menu pizze 🍕** — `menu/menupizze.html`
- **Menu bibite 🥤** — `menu/menubibite.html`
- **Menu dolci 🍪** — `menu/menudolci.html`
- **Contatti ☎️** — Via Appia Lato Itri Fondi(LT),  0771 123456, Aperti tutti i giorni
